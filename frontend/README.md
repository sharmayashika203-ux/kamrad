# KadamFind Frontend Application

This directory contains the production React + Vite application for **KadamFind**.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Vanilla CSS (Tailwind-free custom design system)
- **Icons**: Lucide React
- **Backend SDK**: `@supabase/supabase-js`
- **Payments**: Razorpay Checkout SDK + Safe Test Sandbox Mode
- **Test Runner**: Vitest

---

## 🚦 Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start local Vite development server:
   ```bash
   npm run dev
   ```

3. Run test suite:
   ```bash
   npm run test
   ```

4. Build production bundle:
   ```bash
   npm run build
   ```
